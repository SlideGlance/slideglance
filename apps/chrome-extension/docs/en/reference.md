# chrome-extension — Reference

## App layout

```
apps/chrome-extension/
├── manifest.config.ts       # @crxjs Manifest V3 generator
├── vite.config.ts           # Vite + @crxjs/vite-plugin
├── src/
│   ├── background.ts        # service worker
│   ├── viewer/              # the viewer page (uses @slideglance/viewer)
│   ├── content/             # link-interception content script
│   └── …
├── public/                  # icons, static assets
├── store-assets/            # Chrome Web Store screenshots
├── scripts/                 # render-icons, package
└── docs/en/{index,reference,guides}.md
```

## Manifest highlights

Generated by `manifest.config.ts`. Key fields:

| Field                       | Purpose                                   |
| --------------------------- | ----------------------------------------- |
| `manifest_version`          | `3`                                       |
| `permissions`               | `"declarativeNetRequest"`, `"storage"`    |
| `host_permissions`          | `<all_urls>` (to intercept `.pptx` links) |
| `background.service_worker` | `src/background.ts`                       |
| `web_accessible_resources`  | The viewer HTML + WASM                    |

## Build artefacts

| Path                        | Purpose                     |
| --------------------------- | --------------------------- |
| `dist/`                     | Loadable unpacked extension |
| `slideglance-<version>.zip` | Chrome Web Store upload     |

## Commands

| Script                                                  | Purpose                                   |
| ------------------------------------------------------- | ----------------------------------------- |
| `pnpm --filter @slideglance/chrome-extension dev`       | Vite dev server with HMR                  |
| `pnpm --filter @slideglance/chrome-extension build`     | Production build → `dist/`                |
| `pnpm --filter @slideglance/chrome-extension package`   | Build + zip → `slideglance-<version>.zip` |
| `pnpm --filter @slideglance/chrome-extension typecheck` | `tsc --noEmit`                            |

The `predev` and `prebuild` scripts run
`scripts/run-build-wasm.mjs` so the underlying
`@slideglance/core` WASM is rebuilt before bundling.

## Privacy

No network requests originate from the extension. Decks are parsed
and rendered locally via WASM. See [`PRIVACY.md`](../../PRIVACY.md).
